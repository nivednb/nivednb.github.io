# Living world acceptance contract
Nemix is an optional creative identity, not a mandatory visual architecture.
Goal: an inhabited website, not an animation behind a website.
## Gates
- Spatial continuity: trace agents from visible facility to task to facility; no arbitrary edge spawning.
- Temporal continuity: trace identities across loading, presentation, infrastructure and steady state.
- Causality: completed tasks change visible real interface or world geometry.
- Permanence: completed structures persist and enable later activity.
- Autonomy and rhythm: observe idle and busy periods without visitor input.
- Collective behavior and hierarchy: distinct task scales and coordinated dependencies.
- Emergence: new facilities become operational only after construction.
- Variation: compare nonadjacent observation windows; avoid obvious short loops.
- Information vitality: distinguish verified real repository events from simulated fictional activity. Never fabricate actual updates; show source/time and stale/unavailable state.
- Functional integration: real project links usable promptly; no forced long animation.
- Visual coherence: inspect actual browser screenshots/video across startup, handoff and steady state, desktop and mobile. Code inspection alone is not a visual pass.
- Performance: measure frame timing and resource cost, report hardware/browser and limitations; reduced motion and skip paths remain functional.
## Verification protocol
Record actual observations, screenshots or recordings, measured timings, and pass/fail/not-tested for each gate. Trace at least one complete worker lifecycle and one construction dependency. Compare against previous build. Do not claim visual validation from commits or source alone.
## Information layers
Real events: public repository changes with provenance, timestamps, caching and explicit failure states.
Fictional events: clearly identified simulation of logistics, maintenance, construction and internal activity; can react to real events without misrepresenting them.
## Current status
Existing prototype is experimental and has not passed visual acceptance. User observed edge spawning and infrastructure appearing without construction. Do not promote to root homepage until verified.
