# MyPod compatibility site

This site preserves the earlier `/Classipod/` address for existing MyPod Home
Screen installations. It is a snapshot of the previously published build;
new releases are at https://nivednb.github.io/MyPod/ and the source is at
https://github.com/nivednb/MyPod. Imported music remains on each device.

and the application notices for license information. The compatibility site is
not the upstream project or an official Apple product.
